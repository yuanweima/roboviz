# 常用命令

## 开发命令
```bash
# 安装依赖
pnpm install

# 启动开发服务器 (react-demo)
pnpm --filter roboviz-react-demo dev

# 构建所有包
pnpm build

# 运行测试
pnpm test

# 运行 lint
pnpm lint

# 清理
pnpm clean
```

## Git 相关
```bash
# 查看状态
git status

# 查看差异
git diff

# 提交
git add . && git commit -m "message"
```

## 系统命令 (Darwin/macOS)
```bash
# 查看目录
ls -la

# 查找文件
find . -name "*.ts"

# 搜索内容
grep -r "pattern" .
```
